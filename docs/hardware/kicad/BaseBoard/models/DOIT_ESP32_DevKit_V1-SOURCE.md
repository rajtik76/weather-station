# DOIT ESP32 DevKit V1 (30 pin, micro-USB) STEP model

`DOIT_ESP32_DevKit_V1_30pin_microUSB.step.gz` is `USB-micro_esp32_30pin+PIN.step`
by Josselin Hefti, gzipped unchanged. KiCad reads `.step.gz` directly.

- Source: https://www.printables.com/model/1362332-esp32-devkit-v1-board-30-pin
- License: Creative Commons - Public Domain

The model's origin sits off the pins: the EN pin is at (-0.64, 42.83), the
pin rows are 25.40 mm apart and the black header spacer ends 4.17 mm under the
PCB top. The footprint offsets it by (0.64, -42.83, 12.67) so the spacer rests
on the 8.5 mm female headers.
